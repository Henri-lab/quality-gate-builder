# 项目保护措施总表（protection checklist）

> "企业级"不是工具多，而是每一条都有**自动执行 + 触发即阻断 + 有证据**。

| 保护域 | 措施 | 工具（示例） | 触发即阻断？ |
| --- | --- | --- | --- |
| 代码质量 | lint / 静态分析 | golangci-lint、eslint、ruff | 是（0 warning 或豁免清单只减不增） |
| 单元/集成 | 分层测试 + 覆盖率（diff 覆盖率硬门槛） | 语言测试框架 + Testcontainers | 是 |
| 契约 | MSP/ASP 符合性向量冒烟 | 各协议技能的 smoke 骨架 | 是 |
| 密钥 | 提交前扫描 + 历史扫描 | gitleaks（含 `fetch-depth: 0`） | 是（0 命中） |
| 依赖 | 已知漏洞扫描 | trivy / snyk / govulncheck | 是（高危 0） |
| 迁移 | up→冒烟→down→up；可回滚证明 | 迁移测试 + expand→migrate→contract | 是 |
| 压测 | 基线 + 阈值门禁 | k6 + 阈值脚本 | 是（Q2 起） |
| 分支 | 主分支保护：CI 全绿 + 评审 | GitHub Branch Protection | 是 |
| 发布 | staging 冒烟 → tag → prod → 部署后冒烟 | CI/CD + 自动回滚 | 是 |
| 观测 | 日志/指标/追踪 + 压测期资源盯防 | 统一日志体系 + 监控告警 | 告警即处置 |
| 数据 | 测试数据隔离与清理；生产数据不进测试库 | 自建自清纪律 | 纪律执行 |
| 回滚 | 每发布必带回滚预案；回滚演练 | 版本化迁移 + 部署脚本 | 演练通过才发布 |

验收方式：任一措施无法回答"它怎么自动执行、怎么阻断、证据在哪"，就降级为"待办项"而不是"已完成"。
